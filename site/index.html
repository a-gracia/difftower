The problem

Agents commit. Your diff goes blank.

An agent that works for twenty minutes makes five commits along the way. git diff shows only what is left uncommitted, so you review commit by commit, or you don't. That is how a test quietly edited to pass gets through.

Sessions

One click before the agent starts. One review when it is done.

Start a session

Difftower marks where your code stands right now. Your branches and history are left as they are.

Let the agent work

It edits, commits, edits again. Every change shows up live, and none of it drops out of view when it commits.

Accept or revert

File by file, or all at once. Accepted files leave the list; reverted ones go back to how they were. A revert can be undone.

End the session

Done reviewing: Difftower goes back to showing changes since the last commit. Closing the app in between loses nothing.

Everything else

Only what supervising an agent needs.

A diff that keeps up

Updated as the agent writes, new files included. Unified or split, highlighted, with a minimap. Thousands of files stay smooth.

The agent, right beside it

A terminal in the same window, in the repository: run Claude Code, Codex, Aider or any CLI agent next to its diff.

Many repositories, one window

Open a folder of repositories: one session, one diff and one test list across all of them.

Native and light

Rust on GPUI, the framework behind Zed. Rendered on the GPU, opens at once. No Electron.

Keyboard first

Go to any file with Ctrl+P, step through files and changes with j, k, n, p. Press ? for the rest.

Keeps itself current

It tells you when a new version is out, and updates itself in one click.

Over SSH

Your agents run on a server. So does Difftower.

Point it at user@host:path. It installs a tiny agent there on first connection, watches the repository on the host and sends only diffs. Sessions, protected files and tests work the same. Your keys and ~/.ssh/config work as usual.

Questions

Before you try it.

Does a session touch my git history?

No. It is a git ref under refs/difftower/, kept out of your branches, your log and your pushes. Ending the session deletes it.

What if I close Difftower mid-session?

Nothing is lost. The session lives in the repository, so the next time you open it, it picks up where you left.

Which agents does it work with?

Any of them. Difftower watches the files and git, not the agent, so Claude Code, Codex, Aider or a script all look the same.

Is it an editor?

No, on purpose. It shows, guards, tests and reverts. Writing the code is the agent's job, and your editor is still there for yours.

Install

One line, no root.

Any Linux

Into ~/.local, with a launcher entry. Updates itself.

curl -fsSL https://difftower.com/install.sh | sh

For everyone

Into /usr/local instead of your home.

curl -fsSL https://difftower.com/install.sh \
  | sudo DIFFTOWER_PREFIX=/usr/local sh

From source

Rust, git, clang and lld.

git clone https://github.com/a-gracia/difftower
cd difftower && cargo dt

Needs Linux x86_64 with glibc 2.35 or newer (Ubuntu 22.04, Debian 12, Fedora 36, Arch) and git. macOS is next.
